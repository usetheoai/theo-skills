# Milestone M25 — Servidor de descoberta (MCP)

## Outcome

O pacote passou de biblioteca a servidor. Verificado com o **binário real**, em processo
separado, falando o protocolo por stdio:

```
servidor   : {"name":"theo-skills","version":"0.1.0"}
ferramentas: search_skills, get_skill, load_skill, list_skill_revisions
  search_skills         args: query, top_k, category
  get_skill             args: skill_id
  load_skill            args: skill_id
  list_skill_revisions  args: skill_id
```

Nenhuma aceita `workspace`/`tenant`/`account`. Sem credencial, o processo sai com código 2.

22 testes no pacote (9 novos, pelo cliente MCP oficial) · 217 de integração · 343 de
contrato · CI verde no SHA exato.

## Item declarado incompleto, de propósito

O registro no `theo-traefik-mcp` **não** foi feito. O transporte entregue é stdio — o agente
hospeda o servidor como processo local. O edge MCP serve transporte HTTP por tenant, que é
outra decisão de produto e exige o próprio modelo de autenticação. Marcado `[~]` no roadmap
com a razão, em vez de `[x]` por proximidade.
